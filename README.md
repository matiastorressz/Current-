# Current

**Social investing for crypto.**

CurrentSocial helps investors track their crypto portfolio, understand their allocation and risk, and get AI-powered insights to make more informed decisions.

 **Website:** https://currentsocial.xyz/

## Features

* 📊 Crypto portfolio tracking
* 🤖 AI-powered portfolio analysis
* 📈 Allocation and concentration insights
* ⚠️ Risk analysis
* 🔎 Crypto screeners
* 🌐 Social investing features
* 📉 Estimated upside and downside analysis

## Product

CurrentSocial is designed to make crypto portfolio analysis simpler by combining portfolio tracking, AI, analytics, and social investing tools in one platform.
